# 物业网页页面与导航结构

物业网页目录 `安居云枢网页端(1)/textcursor` 共有 **10 个可访问页面**。主导航将 7 个业务页面收进 3 个任务分组，顶层保留值班台、物业登录和紧急处置，避免全部入口横向平铺。

| 分组 | 数量 | 页面 |
| --- | ---: | --- |
| 核心工作 | 1 | `index.html` 值班台 |
| 基础治理 | 3 | `duty.html` 制度责任、`buildings.html` 数字孪生、`people.html` 人员台账 |
| 巡查整改 | 2 | `inspection.html` 巡查台账、`report.html` 隐患工单 |
| 处置支持 | 2 | `knowledge.html` 处置预案、`agent.html` 处置智能体 |
| 系统与应急 | 2 | `login.html` 物业登录、`emergency.html` 紧急处置 |
| **合计** | **10** |  |

桌面端显示 6 个顶层操作，其中 3 个是分组下拉菜单；宽度不超过 1080px 时切换为折叠菜单。`navigation.js` 统一负责当前页面标记、分组互斥、点击外部或按 Esc 关闭，以及移动菜单状态，不再由各页面脚本分别维护。
