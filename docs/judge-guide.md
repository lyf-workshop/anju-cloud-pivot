# 安居云枢 1.5.0 · 评委安装使用

这是指定比赛评委使用的受控演示版。Windows 面向物业工作人员，Android 面向社区住户；两端连接同一演示服务器，但身份、导航和功能界面不同。

## Windows：物业工作台

1. 从主办方提供的受控地址下载 `Anju-Property-Windows-1.5.0-Setup.exe`，双击安装并打开“安居云枢物业工作台”。
2. 输入主办方单独提供的物业体验账号和密码。账号可勾选“在本机保持登录 7 天”；密码不会写入安装包或下载网页。
3. 体验值班台、居民台账、楼栋与设备、隐患工单、巡查和值班安排。右上角“账号安全”可查看登录设备、退出其他设备或修改密码。

建议顺序：登录 → 值班台 → 楼栋与设备 → 隐患工单 → 登记现场隐患 → 关闭并重新打开 → 确认登录和工单仍可恢复。

安装包未购买 Authenticode 证书，Windows 可能显示 SmartScreen 声誉提示。请先核对下方 SHA-256，再选择“更多信息 → 仍要运行”。

## Android：住户端

1. 下载 `Anju-CloudPivot-Android-1.5.0.apk`，允许当前浏览器或文件管理器“安装未知应用”，然后安装。
2. 打开“安居云枢”，点击“直接体验”。匿名演示资料已预填，无需账号密码，也不要填写真实住址。
3. 建议顺序：首页 → 助手识险并带入上报 → 楼栋设备 → 提交隐患 → 我的记录 → 两步疏散演练 → 总结 → 关闭并重新打开 → 历史记录。

上报成功以服务器生成的 `AJ...` 编号为准。再次打开会自动恢复本机匿名会话；不同安装的私人演示记录相互隔离。系统照片选择器只授权所选图片。如果设备因组织策略、Android 开发者验证或厂商安全策略拒绝侧载，请改用主办方提供的测试设备，不要关闭整机安全防护。
