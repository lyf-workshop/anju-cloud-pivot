# 安居云枢评委体验版 · 安装使用

这是指定评委使用的演示版。主流程为：**下载安装 → 打开应用 → 点击“直接体验” → 确认匿名演示资料**。无需账号、密码、协议勾选，也不要填写真实住址；再次打开会自动恢复本机匿名会话。

## Windows

1. 从主办方提供的受控下载地址取得 `Anju-CloudPivot-Windows-1.4.0-Setup.exe`。
2. 双击安装，按安装向导完成后打开“安居云枢”。当前测试安装包未购买 Authenticode 代码签名证书；若 Windows 显示 SmartScreen 提示，请先核对本页 SHA-256，再选择“更多信息 → 仍要运行”。
3. 首次点击“直接体验”，在“人口登记”页使用系统预填的匿名演示资料，点击“下一步 → 跳过此部分 → 进入首页”；以后启动会直接进入首页。

## Android

1. 下载 `Anju-CloudPivot-Android-1.4.0.apk`，允许当前浏览器或文件管理器“安装未知应用”，然后安装。
2. 打开“安居云枢”，首次点击“直接体验”，确认系统预填的匿名演示资料后进入首页。系统照片选择器只会授权您选中的图片。
3. 如果设备因组织策略、Android 开发者验证或厂商安全策略拒绝侧载，请使用主办方提供的测试设备；不要关闭整机安全防护。

## 建议体验顺序

首页 → 助手识险并带入上报草稿 → 楼栋设备 → 提交隐患 → 查看我的记录 → 两步疏散演练 → 查看总结 → 关闭并重新打开 → 历史记录。上报提交成功以服务器生成的 `AJ...` 编号为准。

所有楼栋、设备、读数、告警、集合点和联系方式均为明确标注的演示资料。应用不会拨打真实紧急电话、控制设备或发送真实告警；请勿填写真实敏感信息。网络中断时会明确提示，离线或过期状态不代表真实环境安全。
