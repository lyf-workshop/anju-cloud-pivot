# 评委体验版发布注意事项

## 适用范围

当前构建只供指定比赛评委在评审期内体验，不代表已获应用商店审核、备案、等保、消防产品认证或面向公众正式运营许可。服务器位于海外，自有域名已启用 HTTPS；若未来面向中国大陆公众持续提供互联网信息服务、使用境内服务器或上架应用商店，应由运营主体另行核对 ICP 备案、公安备案、隐私合规、数据跨境、应用分发和 Android 开发者验证等当时适用要求。

## 安装与签名

- Windows NSIS 安装包已实际安装和验证，但未购买 Authenticode 证书，因此可能触发 SmartScreen 声誉提示。正式公开分发前应使用运营主体的代码签名证书重签并重新验证。
- Android APK 使用仓库外保存的 RSA-3072 发布密钥签名，APK Signature Scheme v2/v3 校验通过。密钥和随机口令位于构建机 `%LOCALAPPDATA%\AnjuCloudPivot\signing`，ACL 仅允许当前构建用户；它们不在 Git、APK 配置或客户端源码中。应离线加密备份，丢失后无法无缝升级同一应用 ID。
- 2026 年 Android 的认证设备侧载规则正在实施[开发者验证要求](https://developer.android.com/developer-verification/guides/pdf-guides/adc-guide.pdf)。当前评委 APK 已在 Android 16 模拟器侧载通过，但真实认证设备仍可能因账号验证、组织策略或厂商安全策略拒绝安装。受控评审应预备已验证的测试设备；这不等同于应用商店上架。

## 数据与安全边界

- 匿名体验按随机安装键映射独立用户，默认会话有效期 90 天，可用 `DEMO_SESSION_TTL_HOURS` 调整。卸载或清除应用数据会生成新身份；旧记录不会暴露给新身份。
- 演示会话只能访问演示数据；服务器限制登录、上传、上报和演练频率。附件仅允许 JPEG/PNG/WebP，单张 5 MiB、每个报告最多 3 张，并解码、重编码和剥离 EXIF。
- 服务器密码、数据库凭据、摄像头密钥、物业口令、Android 签名口令和下载密码均不写入客户端或 Git。
- 当前下载入口受 HTTP Basic Auth 保护并设置 `noindex` / `no-store`，只用于定向评审。评审结束后应撤下安装包、轮换下载密码并按保留政策清理演示会话与附件。
- 居民安全助手和物业处置智能体只用于演示辅助：建议不等于消防鉴定，物业动作必须人工确认。外部模型密钥只允许保存在服务器；当前公网未配置外部模型，使用可测试的本地安全规则。

## 明确不包含

没有接入真实住户、真实消防设备、自动报警、电话拨号、短信/推送或真实疏散导航。设备及告警状态都标注为演示；离线、未知或过期数据不会显示为真实正常。
