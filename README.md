# 安居云枢 · 页面展示版

微信原生 JavaScript / WXML / WXSS。15个业务页面、四项底部导航及5个辅助页面，使用统一的本地示例数据。

**不需要服务器、AppSecret、云开发或数据库，也不需要安装 npm 依赖才能展示。** 旧后端代码保留，当前小程序不调用它。

## 导入运行

1. 打开微信开发者工具，导入当前 `miniprogram-1` 根目录（包含 `app.json` 和 `project.config.json`）。
2. 保留项目现有 AppID；若无该 AppID 的开发权限，可使用你有权限的测试号。展示流程不调用真实微信登录。
3. 选择基础库3.17.3，点击“编译”，从登录页开始。无需构建npm、设置服务器域名或关闭域名校验。

`npm run dev` 只打印导入路径，不会启动服务。所有素材放在本地 `assets/`。

## 主要演示流程

- 登录：协议默认未勾选；阅读说明并勾选后，点击“微信一键登录”进入首页。此操作仅进入演示。
- 首页、隐患、楼栋、我的：四个底部入口正常切换；首页卡片进入对应页面。
- 隐患：按待处理/处理中/已完成筛选示例，点击查看各自详情；填写类型、楼层、位置、描述后模拟提交，结果、详情和我的上报展示本次填写内容。照片最多3张，可选择、预览、删除，**不会上传**。
- 楼栋与设备：默认云栖花园1号楼1单元6层，切换楼层查看对应设备。7层含离线示例，其余读数也都是固定展示数据。
- 演练：楼栋 → 安全出口 → 集合点 → 结束总结 → 我的演练记录；时长由开始和结束时间计算。“再次演练”创建新记录，“返回楼栋”切回主页面。线上模拟不代表实际疏散。
- 紧急求助：展示119、示例物业号码和住址；所有电话按钮**只弹演示提示，不实际拨号**。
- 我的：查看示例记录、编辑示例资料和住址；退出返回登录页并恢复初始示例数据。

## 数据与后续替换位置

- `mock/data.js`：统一社区、楼栋、设备、用户、隐患、公告、演练和说明文本。
- `mock/store.js`：本次运行的内存数据。退出或重新启动后恢复示例，不要求跨设备或关闭应用后的保存。
- `services/repository.js`：所有页面使用的本地数据函数。将来接服务器时替换这里，再按后续需求接入真实登录、图片上传等能力。
- `services/session.js`：仅演示登录标记；`services/selection.js`：当前选择的示例楼层。
- `server/`、旧HTTP模块和 `backend:*` 命令是延期功能，不在本轮运行链路。旧版说明与被替换的数据层保存在 `docs/archive/connected-mvp/`。

## 重跑模拟器检查（可选）

正常展示不需要以下验收依赖。需重跑时，在PowerShell项目目录执行：

```powershell
npm install --prefix artifacts/devtools-runner --no-package-lock --no-audit --no-fund miniprogram-automator
& 'D:\DevTools\wechat_devtools\微信web开发者工具\cli.bat' auto --project (Get-Location).Path --auto-port 9420
node scripts/verify-devtools.cjs
node scripts/check-scroll-devtools.cjs
```

将CLI路径替换为本机安装位置。开发者工具须打开当前项目，并在“设置 → 安全设置”开启服务端口；本次该设置已完成。脚本先将截图写到系统临时目录，断开后归档到 `artifacts/`，避免保存截图触发项目热重载。验收文件及工具依赖均不参与小程序打包。
