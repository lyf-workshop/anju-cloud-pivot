# 安居云枢消防安全应急报警平台

面向业主、物业、访客的小区消防信息公开与服务站（本地演示版）。

## 1）推荐技术栈

**纯 HTML + CSS + 原生 JS（多页静态站）**
理由：零构建、双击/本地服务器即可预览，小白最容易改文字与电话，后续也能平滑换成任意托管。

## 2）页面清单（站点地图）

| 页面 | 文件 | 目的 |
|------|------|------|
| 首页 | `index.html` | 左仪表盘 + 中 3D 楼房 + 右户数/车辆/电动车统计 |
| 制度责任 | `duty.html` | 责任人公示与通俗制度 |
| 3D 楼房 | `buildings.html` | 各楼栋疏散与设施信息、微型站 |
| 巡查公示 | `inspection.html` | 巡查与隐患整改公示表 |
| 知识演练 | `knowledge.html` | 逃生知识与演练时间线 |
| 隐患上报 | `report.html` | 上报表单（前端模拟提交） |
| 紧急指引 | `emergency.html` | 一键拨号与疏散要点 |

共用资源：`styles.css`、`script.js`（Logo 暂未定，顶栏为占位色块）

## 3）色彩与字体变量

在 `styles.css` 的 `:root` 中：

- 主色 `--brand: #9b2c2c`（砖红消防感）
- 辅色 `--steel: #2f4550`（深灰蓝）
- 背景 `--bg: #eef1f3`
- 文字 `--ink: #1a2228` / 次要 `--muted: #5a6670`
- 警示 `--warn: #b45309` / 成功 `--ok: #2f6b4f`
- 字体：`Noto Sans SC`（正文）+ `Noto Serif SC`（标题），经 Google Fonts 引入

## 本地打开方式

### 方式 A：本地服务器（推荐）

在项目目录执行：

```bash
python -m http.server 5173
```

浏览器打开：http://127.0.0.1:5173/

### 方式 B：直接打开文件

用浏览器打开 `index.html`（部分环境对本地路径限制更严，优先用方式 A）。

## 如何修改内容

1. **小区名 / 平台名**：改各 HTML 里的「安居云枢」「阳光家园」文案；Logo 确定后放到 `assets/` 并替换顶栏占位色块。
2. **电话 / 地址**：全局搜索 `400-800-9000`、地址行并替换；保持 `href="tel:..."` 与显示号码一致。
3. **责任人姓名**：编辑 `duty.html`。
4. **户数 / 车辆 / 电动车数据**：编辑 `index.html` 中带 `data-count="数字"` 的属性。
5. **楼栋信息**：编辑 `buildings.html`，以及 `script.js` 里的 `buildingData`。
6. **图片**：按 `assets/placeholders/README.txt` 放入实景图；`buildings.html` / `styles.css` 中已标注占位说明。
