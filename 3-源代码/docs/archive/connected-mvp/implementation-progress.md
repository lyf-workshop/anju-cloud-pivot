## 技术与实施决策
- 保留原生 JavaScript 小程序；服务端 TypeScript + Fastify + Node 内置 SQLite，避免本机 SQLite 二进制编译依赖。Node 最低 22.13。
- 演示适配器与真实 API 适配器共用 HTTP 业务契约；演示也连接本地后端，独立数据库，固定种子，无静默回退。
- 原生导航栏和原生四项 tabBar 负责微信胶囊、系统状态栏和底部安全区域；公共业务卡片、按钮、表单和状态组件复用统一样式。
- 住址为自报绑定 pending，绝不自动认证。公共楼栋资料不代表住户审核。私人记录与附件严格以业务会话用户鉴权。
- 演练时长累计前台停留，客户端保存毫秒累计检查点，服务端单调合并、上限校验；后台暂停，结束幂等，快照保存。
