## 重点业务断言

- 新用户无默认住址；自报绑定是pending，不能自动认证。
- 用户B读取A的报告、图片、演练返回404；使用A的附件创建报告403；通过userId伪造身份被拒绝。
- 缺少楼栋绑定不能在对应楼栋创建报告/演练或读取设备。
- 社区列表没有联系方式、私有位置、描述、附件或上报人ID。
- 同幂等键报告只创建一次；不同内容同键409；同演练重复结束不改变已保存时长与时间。
- 上传非图片、错误MIME、超过5MiB、4张附件、重复使用其他报告附件被拒绝。
- 没有物业操作时新报告只有一条待处理事件。
- 演练不在加载时完成步骤；先exit再assembly；缺步骤结束409；超出经过时间的时长400；完成和中止不可互相转换。
- 重新打开数据库后用户会话、报告和演练仍可读；列表、详情和统计一致；模板变化不改变历史快照。
- 心跳不解除告警；较旧clear事件不覆盖较新alarm；没有读数显示null、固定旧读数stale、无通信unknown。
- 退出会话被服务端拒绝，公共config仍可访问；客户端清理保留页面内存和私有草稿，避免换号残留。
